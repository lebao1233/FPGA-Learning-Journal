# FPGA-Learning-Journal
My personal learning journal capturing FPGA design exercise, simulation testbenches, and hardware implementations with tang nano 9k
## Repository Structure
- **01-Blinking-LED**: Basic clock divider and GPIO control
- **02-Flipflop**: D-FlipFlop design with a debounce filter for mechanical buttons
- **03-shift-register**: Ring shift register logic
- **04-UART-RX**: UART Receiver module with start/stop bit detection
- **05-UART-Loopback**: Full UART TX/RX loopback system with Tera Terms

## Tools & Hardware
- **Hardware**: Tang Nano 9K (Gowin GW1NR-9 FPGA)
- **Software**: Gowin EDA 
- **Language**: Verilog HDL
